# httpx Tool

live subdomains

```
# httpx Save only live subdomains
httpx -l subs.txt -silent -o live.txt

#Status codes (200, 403, etc.)|Page titles|Technologies used|IP addresses
httpx -l subs.txt -status-code -title -tech-detect -ip

```
