# Web-recon

## Subdomain

In the [Domain Name System](https://en.wikipedia.org/wiki/Domain_Name_System) (DNS) hierarchy, a subdomain is a [domain](https://en.wikipedia.org/wiki/Domain_name) that is a part of another (main) domain.

Find Subdomains

```
# subfinder
subfinder -d www.google.com -o subs.txt

# subfinder -silent show only subdomains in output
subfinder -d www.google.com -silent -o subs.txt
```
